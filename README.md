#### Introducing NetPass:
Over the years, the 3DS has sadly declined in popularity. Because of this, StreetPass interactions have become increasingly rare, as people going outside with their 3DS (let alone using their 3DS regularly) become fewer and further between. That's where NetPass comes in!

Unlike StreetPass, NetPass works over the internet, allowing you to exchanges passes with users all over the world. Upon opening NetPass, you are given the option of various "locations" to choose from. After choosing a location, you will periodically exchange passes with other users in the same location over a 10 hour period. Once the 10 hours are up, you may choose a new location and repeat the process.

It is important to note that NetPass does not replace StreetPass, it simply supplements it. You can still get StreetPass passes as you normally would, and any passes exchanged via NetPass will function identically to those exchanged via StreetPass.

> [!IMPORTANT]
> - For more information about NetPass, please refer to the [Usage Guide](https://netpass.cafe/usage.html).
> - Usage of NetPass is subject to its [Rules](https://netpass.cafe/rules.html) and [Privacy Policy](https://netpass.cafe/privacy.html).
> - Before installing NetPass, ensure your 3DS is on [system software 11.15 or higher](https://3ds.hacks.guide/finalizing-setup.html#section-ii-updating-the-system), and has the [latest version of Luma3DS firmware installed](https://3ds.hacks.guide).

## Prerequisites

### For the NetPass 3DS homebrew
The NetPass homebrew application is built upon the `devkitPro` toolchain, which you can setup by following [these instructions](https://devkitpro.org/wiki/Getting_Started). Once installed, use [devkitPro pacman](https://devkitpro.org/wiki/devkitPro_pacman) to install the following required packages:
- `3ds-dev`
- `3ds-curl`
- `3ds-opusfile`

You will also need to install `bannertool`, which you can find [here](https://github.com/Epicpkmn11/bannertool/releases/latest). Once installed, the executable corresponding to your system should be placed into `$DEVKITPRO/tools/bin`.

For compiling the NetPass application as a `.cia` file, you will also need to install `makerom`, found [here](https://github.com/3DSGuy/Project_CTR/releases). Once installed, this executable should also be placed into `$DEVKITPRO/tools/bin`.

#### Additional prerequisites for Linux users
Use your system's package manager to install the following:
- [FFmpeg](https://ffmpeg.org/)
- [Python](https://www.python.org)
  - [Python-PyYAML](https://pypi.org/project/PyYAML/)
  - [Python-Requests](https://pypi.org/project/requests/)

#### Additional prerequisites for Windows users
devkitPro on Windows uses MSYS2 to emulate a Unix-like environment for compilation. Additional steps should be taken to ensure that this environment is set up properly:
- Add the `mingw64` repository to `pacman` by adding the following to `/etc/pacman.conf`:
  ```ini
  [mingw64]
  Server = https://repo.msys2.org/mingw/mingw64
  ```
- Run `pacman -Sy` to update repository package list.
- Run `pacman -S mingw-w64-x86_64-ffmpeg` to install FFmpeg.
  - Add `/mingw64/bin` to MSYS2's `PATH` environment variable if it isn't there already. To make this permanent, add the following line to `/etc/bash.bashrc` then close and reopen your MSYS2 terminal:
    ```bash
    export PATH="$PATH:/mingw64/bin"
    ```
- Run `pacman -S python python-requests python-yaml` to install Python and its necessary dependencies.

### For the sysmodule patches
You will need to install the following tools. Make sure they are in your ``PATH`` environment variable.
- [armips](https://github.com/Kingcom/armips)
- [flips](https://github.com/Alcaro/Flips)

You will also have to manually dump the decrypted code of each of the sysmodules to patch from a 3DS, and then place the file as `code.bin` into the respective patch folder.
- Boot into [GodMode9](https://github.com/d0k3/GodMode9)
- Press the Home button, select ``Title manager`` and press A
- Select ``[1:] NAND / TWL`` and press A
- For each sysmodule:
  - Find its TitleID in the list
    - BOSS: ``0004013000003402``
    - CECD: ``0004013000002602``
    - NS: ``0004013000008002``
    - SSL: ``0004013000002F02``
  - Select it and press A
  - Select ``Open title folder`` and press A
  - Without changing your selection, press A
  - Select ``NCCH image options...`` and press A
  - Select ``Extract .code`` and press A
  - Wait for the operation to finish. When prompted, press A to continue
- Plug your SD card into your computer
- You should find files named ``<TitleID>.dec.code`` with ``<TitleID>`` being the TitleIDs of each sysmodule
- Copy them over to their respective folder (under ``./patches/<sysmodule name>/``)
- Rename each file into ``code.bin``

## Compilation
This project ships with a [Makefile](Makefile), which is meant to simplify the compilation process. If you're unfamiliar with them, you can find out more about GNU Make [here](https://www.gnu.org/software/make/).

### For the NetPass 3DS homebrew
To compile as `.3dsx`:
```bash
make
```

To compile as `.cia` (and `.3dsx`):
```bash
make cia
```

You will find the compiled binaries in the ``./out/`` directory.

> [!TIP]
> The debug version of the NetPass application can be compiled instead by appending `DEBUG=1` to the beginning of the above commands. For example, to compile the debug version as `.cia`, use:
> ```bash
> DEBUG=1 make cia
> ```

### For the sysmodule patches
```bash
make patches
```

You will find the resulting `.ips` patches in the ``./romfs/patches`` directory.
